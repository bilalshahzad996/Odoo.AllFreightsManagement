SHP

Shipment Management

REFFEATUREDESCRIPTIONCLASS
SHP-001 Job File (Shipment) Complete shipment record covering import and export directions. Tracks all parties — customer, shipper, consignee — with full audit trail and chatter history. CORE
SHP-002 Multi-Transport Mode Sea, Air, and Land modes selectable per shipment. Mode-appropriate fields and validations adapt accordingly. CORE
SHP-003 Multi-Leg Routing Full transshipment support via a dedicated Legs tab. Each leg captures origin/destination ports, carrier, vessel, voyage number, B/L, ETD, ETA, and status independently. NEW
SHP-004 Incoterms Standard trade terms (EXW, FOB, CIF, DAP …) linked to every shipment, with correct liability and cost allocation recorded on the job file. CORE
SHP-005 Booking & B/L References Master B/L, booking reference, and customs declaration numbers stored and searchable. Essential for port release and customs clearance workflows. CORE
CTR

Container & Cargo Tracking

REFFEATUREDESCRIPTIONCLASS
CTR-001 Container Master Container number, type (20GP/40HC/45HC/20RF …), seal number, tare weight, gross weight, and volume per container per shipment. CORE
CTR-002 HS Code & Commodity HS code, commodity description, package count, and country of origin recorded per container. Powers customs declarations and duty classification. CORE
CTR-003 Customs Valuation Customs value in any currency per container, converted to company currency automatically. Used for duty calculations and insurance assessments. CORE
CTR-004 Tracking Status & URL Per-container tracking status (Unknown / In Transit / Arrived / Delivered) and a live tracking link generated from the carrier's URL template with the container number substituted. NEW
CAR

Carriers, Shipping Lines & Ports

REFFEATUREDESCRIPTIONCLASS
CAR-001 Shipping Line Master Carrier name, SCAC code, transport mode, and operating routes. Shared across all shipments with multi-company isolation where required. CORE
CAR-002 Demurrage Settings Free days and daily demurrage rate configured per shipping line. Drives automatic demurrage calculation on arrived shipments. AUTO
CAR-003 Tracking URL Templates Carrier-level tracking URL template with {container} placeholder. Container records generate clickable live-tracking links automatically. AUTO
PRT-001 50+ World Ports Pre-seeded port master with UN/LOCODE codes covering major hubs across Asia-Pacific, Europe, Americas, Middle East, Africa, and Indian subcontinent. CORE

FIN

Financials & Charges

REFFEATUREDESCRIPTIONCLASS
FIN-001 Multi-Currency Charges Charge lines in any currency (Ocean Freight, THC, Port Clearance, Customs, Documentation, Insurance, Handling, Demurrage …). Each charge linked to a type category with GL account mapping. CORE
FIN-002 Auto Currency Conversion Charges entered in any currency are automatically converted to the company currency using Odoo's live exchange rates. Totals always displayed in company currency. AUTO
FIN-003 Demurrage Auto-Calculation On arrival, free days are counted from the actual arrival date. Days beyond the free period multiplied by the carrier's daily rate and container count, producing a demurrage charge with one click. AUTO
FIN-004 Customer Invoice Generation Creates a validated Odoo invoice from shipment charges in one click. Charge type GL accounts pre-populate invoice lines. Manager can review and post. CORE
FIN-005 Vendor Bill Generation Groups charges by vendor partner and creates one bill per vendor automatically. Matching expense accounts from charge type configuration are applied to each line. CORE
FIN-006 Tariff / Rate Card Tariff records define rates by origin port, destination port, carrier, and container type. The "Apply Tariff" action matches and creates charges from the rate card in bulk. NEW
WFL

Workflow & Compliance

REFFEATUREDESCRIPTIONCLASS
WFL-001 State Validation Guards Mandatory field checks enforced at each state transition. Cannot move to Booked without customer, shipper, consignee, and ports. Cannot move In Transit without ETD and booking reference. Cannot mark Arrived without ETA. CORE
WFL-002 Manager Approval Workflow High-value shipments (configurable charge threshold in company settings) require manager-group approval before booking. Prevents unauthorized commitment of large freight costs. CORE
WFL-003 Multi-Company Support Shipping lines and ports can be shared globally or restricted per company. IR rules enforce record-level isolation across multi-company Odoo environments. CORE
WFL-004 Date Constraint Validation ETA cannot be earlier than ETD — enforced by a Python constraint on save. Arrival date and delivery date are set automatically when transitioning to Arrived and Delivered states. CORE
RPT

Reporting & Notifications

REFFEATUREDESCRIPTIONCLASS
RPT-001 Shipment PDF Report Printable job file / Bill of Lading report covering all shipment details, container list, charge summary, parties, and port information. Accessible directly from the shipment form. PDF
RPT-002 ETA Approaching Alert Scheduled cron runs daily. Any in-transit shipment with ETA exactly 3 days out triggers an automated email to the customer — once per shipment, tracked by flag to prevent duplicates. CRON
RPT-003 State Change Notifications Every state transition sends a styled HTML email to both the Customer and the Consignee. Email includes status banner, shipment details table, port info, carrier, ETD/ETA, B/L, and container count — color-coded by state. AUTO
RPT-004 KPI Graph & Pivot Views Pre-built graph view (bar/line/pie) and pivot analysis for shipment volumes, charge totals, and state distributions. Usable directly from the Shipments list. KPI
RPT-005 Charge Type Analysis Charges are categorised (Freight, Port, Clearance, Documentation, Handling, Insurance, Other) enabling breakdowns by category across any date or shipment filter. KPI
